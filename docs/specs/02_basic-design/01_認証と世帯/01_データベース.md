## テーブルの関係

- User 1 — 0..1 Membership（1 人が所属できる世帯は 1 つだけ）
- Household 1 — 1..n Membership
- Household 1 — 0..n Invitation
- User 1 — 0..n Session・Account（Better Auth が使う）

## User（利用者）

Better Auth が作るテーブル。Google から受け取った名前とメールアドレスを保存する。

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | Better Auth が作る ID |
| name | 名前 | text | ○ | | Google の名前 |
| email | メールアドレス | text | ○ | ○ | Google のメールアドレス |
| emailVerified | メール確認済み | boolean | ○ | | Better Auth が使う |
| image | 画像 | text | | | Better Auth が使う（画面には表示しない） |
| createdAt | 作成日時 | timestamptz | ○ | | 作成日時 |
| updatedAt | 更新日時 | timestamptz | ○ | | 更新日時 |

## Session・Account・Verification（ログイン状態）

- Better Auth が決める列をそのまま使うこと（Better Auth の CLI で Prisma のスキーマを作る）。アプリのコードからは直接読み書きしない。
- `Session` はログイン状態、`Account` は Google アカウントとの結び付き、`Verification` はログインの途中で使う一時的な値を保存する。

## Household（世帯）

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | cuid |
| name | 世帯名 | text | ○ | | 世帯名。1〜20 文字 |
| createdAt | 作成日時 | timestamptz | ○ | | 作成日時 |
| updatedAt | 更新日時 | timestamptz | ○ | | 更新日時 |

## Membership（世帯への所属）

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | cuid |
| userId | 利用者ID | text | ○ | ○ | User.id への参照。1 人 1 行だけ |
| householdId | 世帯ID | text | ○ | | Household.id への参照 |
| role | 役割 | enum `MemberRole`（`OWNER` / `MEMBER`） | ○ | | `OWNER` = オーナー、`MEMBER` = 一般 |
| createdAt | 参加日時 | timestamptz | ○ | | 参加した日時 |

- 世帯から退出したときは、その人の行を消すこと。行が無い人は世帯に未所属として扱う（退出した人が別の招待コードで再び参加できるようにするため）。

## Invitation（招待コード）

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | cuid |
| householdId | 世帯ID | text | ○ | | Household.id への参照。参加先の世帯 |
| code | 招待コード | text | ○ | ○ | ハイフンを除いた 8 文字 |
| createdByUserId | 発行者ID | text | ○ | | User.id への参照。発行した人 |
| expiresAt | 有効期限 | timestamptz | ○ | | 有効期限（発行から 7 日後） |
| usedByUserId | 使用者ID | text | | | User.id への参照。参加に使った人。未使用なら空 |
| usedAt | 使用日時 | timestamptz | | | 参加に使われた日時。未使用なら空 |
| createdAt | 発行日時 | timestamptz | ○ | | 発行日時 |

- `householdId` と `expiresAt` の組み合わせに索引を付けること（設定画面で、世帯の使えるコードを一覧にするため）。
