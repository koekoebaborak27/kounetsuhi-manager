# S07 設定

## 目的

世帯名の変更、メンバーと招待コードの確認、招待コードの発行、契約の一覧、世帯からの退出、ログアウトを 1 画面で行う。

## 表示項目

上から次の順に並べる。PC（幅 1024px 以上）では、左に「世帯名・メンバー・招待コード」、右に「契約」を並べ、その下に「世帯から退出」「ログアウト」を置く。

| 区画 | 項目 | 内容 |
|---|---|---|
| 世帯名 | 世帯名 | 所属している世帯の名前と「変更」ボタン |
| メンバー | 各行 | 名前・メールアドレス・「オーナー」または「一般」。参加した順に並べる |
| 招待コード | 見出しの横 | 「コードを発行」ボタン |
| 招待コード | 各行 | コード（「K7Q2-9XMA」の形）・「YYYY/MM/DD まで・1 回限り」・「コピー」ボタン。発行が新しい順に並べる |
| 招待コード | 行が無いとき | 「使える招待コードはありません。」 |
| 契約 | — | F02 の [`10_設定の契約一覧.md`](../02_契約/10_設定の契約一覧.md) に従う |
| 退出 | ボタン | 「世帯から退出」。一般メンバーにだけ表示する |
| ログアウト | ボタン | 「ログアウト」 |

- 招待コードの一覧には、この世帯のコードのうち、未使用で有効期限が切れていないものだけを出すこと。

## 入力チェック

| 項目 | チェック | 表示する文言 |
|---|---|---|
| 世帯名 | 空（前後の空白を除いて 0 文字） | 世帯名を入力してください。 |
| 世帯名 | 前後の空白を除いて 21 文字以上 | 世帯名は20文字以内で入力してください。 |

## 操作と遷移先

| 操作 | 動き | 遷移先 |
|---|---|---|
| 世帯名の「変更」を押す | 世帯名を入力欄に切り替え、「保存」「キャンセル」ボタンを出す | — |
| 世帯名の「保存」を押す（チェックを通過） | 世帯名を保存し、表示に戻す | — |
| 世帯名の「キャンセル」を押す | 入力を捨て、元の世帯名の表示に戻す | — |
| 「コードを発行」を押す | 招待コードを 1 つ作り、一覧の先頭に加える | — |
| 「コピー」を押す | ハイフンつきのコードをクリップボードに入れ、ボタンの文字を 2 秒間「コピーしました」に変える | — |
| 契約の操作 | F02 の [`10_設定の契約一覧.md`](../02_契約/10_設定の契約一覧.md) に従う | S08 契約 |
| 「世帯から退出」を押す | 確認を出す（下記） | — |
| 確認で「退出する」を押す | 自分の所属を消す | S02 初回設定 |
| 確認で「キャンセル」を押す | 確認を閉じる | — |
| 「ログアウト」を押す | 確認を出さずにログアウトする | S01 ログイン |

- 退出の確認では、「世帯から退出しますか？退出すると、この世帯の記録は見られなくなります。」と表示し、「退出する」「キャンセル」ボタンを置くこと。
- 「コードを発行」を押してから処理が終わるまでは、このボタンを押せなくすること。

## 権限による差

| 操作 | オーナー | 一般 |
|---|---|---|
| 「世帯から退出」 | 表示しない | 表示する |
| 上記以外 | できる | できる |

## エラー時の表示文言

| 場面 | 表示する文言 |
|---|---|
| クリップボードに入れられなかったとき | コピーできませんでした。コードを長押しして選択してください。 |
| オーナーが退出しようとしたとき（画面を開いた後に役割が変わった場合など） | オーナーは世帯から退出できません。 |

このほか、入力チェックの表と [`../00_全体共通.md`](../00_全体共通.md#共通のエラー表示) の共通の文言を使う。

## DB への影響

| 操作 | テーブル | 内容 |
|---|---|---|
| 世帯名の保存 | Household | `name` を更新する |
| コードを発行 | Invitation | 1 行作る（`expiresAt` = 発行時刻の 7 日後）。コードが既存のものと重なったときは作り直す |
| 世帯から退出 | Membership | 自分の行を消す。自分が発行した招待コードは消さず、そのまま使える |
| ログアウト | Session | 自分のログイン状態の行を消す |
