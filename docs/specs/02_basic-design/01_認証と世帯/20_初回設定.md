# S02 初回設定

## 目的

世帯に所属していない人が、招待コードで家族の世帯に参加するか、世帯を新しく作る。

## 表示項目

| 項目 | 内容 |
|---|---|
| 見出し | 「初回設定」 |
| 説明 | 「家族から招待コードを受け取った場合は、入力して参加してください。」 |
| 招待コード | 入力欄。見本として「例：K7Q2-9XMA」を薄く表示する |
| ボタン | 「参加する」 |
| 区切り | 「または」 |
| 見出し | 「新しく世帯を作成する」 |
| 世帯名 | 入力欄。見本として「例：山田家」を薄く表示する |
| ボタン | 「世帯を作成」 |

- タブは表示しないこと。

## 入力チェック

「参加する」と「世帯を作成」は別々にチェックし、押したほうの入力欄だけを確かめること。エラーは該当する入力欄の下に表示する。

| 項目 | チェック | 表示する文言 |
|---|---|---|
| 招待コード | 空（空白・ハイフンだけの場合を含む） | 招待コードを入力してください。 |
| 招待コード | 使える文字 8 文字の形になっていない、または DB に無い | 招待コードが見つかりません。入力した内容を確認してください。 |
| 招待コード | 使用済み | この招待コードはすでに使われています。家族に新しいコードを発行してもらってください。 |
| 招待コード | 有効期限切れ | この招待コードは有効期限が切れています。家族に新しいコードを発行してもらってください。 |
| 世帯名 | 空（前後の空白を除いて 0 文字） | 世帯名を入力してください。 |
| 世帯名 | 前後の空白を除いて 21 文字以上 | 世帯名は20文字以内で入力してください。 |

- 招待コードの照合方法は [`00_認証と世帯共通.md`](00_認証と世帯共通.md#招待コード) に従う。
- 世帯名は前後の空白を除いて保存すること。

## 操作と遷移先

| 操作 | 動き | 遷移先 |
|---|---|---|
| 「参加する」を押す（チェックを通過） | コードの世帯に一般メンバーとして参加し、コードを使用済みにする | S03 ホーム |
| 「世帯を作成」を押す（チェックを通過） | 世帯を作り、自分をオーナーとして所属させる | S03 ホーム |

- ボタンを押してから処理が終わるまでは、両方のボタンを押せなくすること（二重に参加・作成しないため）。
- 処理の直前にすでに世帯に所属していることが分かったときは、何も変更せずに S03 へ移すこと。

## エラー時の表示文言

入力チェックの表のほか、[`../00_全体共通.md`](../00_全体共通.md#共通のエラー表示) の共通の文言を使う。

## DB への影響

| 操作 | テーブル | 内容 |
|---|---|---|
| 参加する | Membership | 自分の行を 1 行作る（`role` = `MEMBER`、`householdId` = コードの世帯） |
| 参加する | Invitation | 使ったコードの `usedByUserId`・`usedAt` を入れる |
| 世帯を作成 | Household | 1 行作る |
| 世帯を作成 | Membership | 自分の行を 1 行作る（`role` = `OWNER`） |

- 「参加する」の 2 つの更新は、1 つのトランザクションで行うこと。同じコードで 2 人が同時に参加しようとしたときは、先に処理された 1 人だけを参加させ、もう 1 人には使用済みの文言を表示すること。
- 「世帯を作成」の 2 つの更新も、1 つのトランザクションで行うこと。
