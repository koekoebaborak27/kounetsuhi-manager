# F03 検針票の記録 — データベース

テーブル名・列名は `prisma/AGENTS.md` の命名規約に従う。型は PostgreSQL の型で書く。

## 目次

- [テーブルの関係](#テーブルの関係)

## テーブルの関係

- Household 1 — 0..n MeterReading
- Contract 1 — 0..n MeterReading
- MeterReading 1 — 0..n MeterReadingItem
- ContractItem 1 — 0..n MeterReadingItem

## MeterReading（検針票）

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | cuid |
| householdId | 世帯ID | text | ○ | ○（utilityType・usageMonth と組み合わせて） | Household.id への参照 |
| contractId | 契約ID | text | ○ | | Contract.id への参照 |
| utilityType | 種別 | enum `UtilityType` | ○ | ○（householdId・usageMonth と組み合わせて） | 種別。契約の種別と同じ値を入れる |
| usageMonth | 使用月 | date | ○ | ○（householdId・utilityType と組み合わせて） | 使用月（その月の 1 日） |
| billingMonth | 請求月 | date | | | 請求月（その月の 1 日） |
| amount | 請求額 | integer | ○ | | 請求額（税込・円）。0〜999,999 |
| periodStart | 使用期間の開始日 | date | | | 使用期間の開始日。画面では必須だが、必須にする前に空で保存した検針票があるため、列は空を許す |
| periodEnd | 使用期間の終了日 | date | | | 使用期間の終了日。開始日以降 |
| usage | 使用量 | numeric(6,1) | | | 使用量。0〜99,999.9 |
| memo | メモ | text | | | メモ。200 文字以内 |
| createdAt | 作成日時 | timestamptz | ○ | | 作成日時 |
| updatedAt | 更新日時 | timestamptz | ○ | | 更新日時 |

- `periodStart` と `periodEnd` は、両方とも入っているか、両方とも空かのどちらかとすること。
- 種別を契約から引かずにこのテーブルにも持つのは、「同じ種別・同じ使用月で 1 件」を DB の一意の条件で守るため。
- 行を消すのは、S04 の「検針票を削除」だけとすること。検針票の内訳の行も同じトランザクションで消す。

## MeterReadingItem（検針票の内訳）

金額を入力した内訳項目だけを保存する。

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | cuid |
| meterReadingId | 検針票ID | text | ○ | ○（contractItemId と組み合わせて） | MeterReading.id への参照 |
| contractItemId | 契約の内訳項目ID | text | ○ | ○（meterReadingId と組み合わせて） | ContractItem.id への参照 |
| name | 項目名 | text | ○ | | 入力したときの項目名の控え |
| category | 分類 | enum `ItemCategory` | ○ | | 入力したときの分類の控え |
| amount | 金額 | integer | ○ | | 金額（円）。割引・補助は負。−999,999〜999,999 |
| quantity | 数量 | numeric(6,1) | | | 数量。0〜99,999.9 |
| unitPrice | 単価 | numeric(7,3) | | | 単価。−9,999.999〜9,999.999 |
| sortOrder | 並び順 | integer | ○ | | 入力画面での並び順。小さいほど上 |

- 項目名と分類の控えを持つのは、契約の内訳項目を外したり分類を変えたりしても、登録済みの検針票の内訳が変わらないようにするため。
- 検針票を保存するたびに、その検針票の内訳の行を入力画面の内容で置き換えること（金額を空にした項目の行は残さない）。
