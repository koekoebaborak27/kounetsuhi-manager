# S05 記録

## 目的

使用月を 1 か月ずつ切り替えながら、電気・ガス・水道の検針票が登録済みかを確かめ、作成・編集の画面を開く。過去の月へさかのぼって登録するときにも使う。

## 表示項目

| 項目 | 内容 |
|---|---|
| 見出し | 「記録」 |
| 月の切り替え | 「◀」・「YYYY 年 M 月分」・「▶」 |
| 種別ごとの行 | 電気・ガス・水道の順に 1 行ずつ。内容は下の表 |

| 行の状態 | 表示 |
|---|---|
| 検針票が登録済み | 種別名・請求額・「編集」ボタン。水道は請求額の後ろに「（7-8月分）」の形で期間を添える |
| 未登録 | 種別名・「未登録」・「作成」ボタン |
| 水道で、前月の検針票が登録済みかつ表示中の月が未登録 | 種別名・「隔月のため記録なし」（薄い文字）・「作成」ボタン |

- 最初に開いたときは、前月（今日が属する月の前の月。日本時間）を表示すること。
- 表示中の月は URL に持たせること（例：`?month=2026-08`）。入力画面から戻ったときや、再読み込みしたときに同じ月を表示するため。URL の月が正しくない、または扱える範囲の外のときは前月を表示すること。

## 入力チェック

なし。

## 操作と遷移先

| 操作 | 動き | 遷移先 |
|---|---|---|
| 「◀」を押す | 1 か月前を表示する。表示中が 2000 年 1 月のときは押せない | — |
| 「▶」を押す | 1 か月後を表示する。表示中が翌月のときは押せない | — |
| 「作成」を押す | — | S04 検針票の入力（作成。種別と使用月はこの行と表示中の月） |
| 「編集」を押す | — | S04 検針票の入力（その検針票の編集） |

- 扱える月の範囲は [`00_検針票の記録共通.md`](00_検針票の記録共通.md#扱える使用月の範囲) に従う。
