# S04 検針票の入力

## 目的

検針票 1 枚分の請求額・使用量・内訳を記録する。新規作成と編集は同じ画面とする。

## 開き方

| 開く元 | 種類 | 渡すもの | 「元の画面」 |
|---|---|---|---|
| S05 記録の「作成」 | 作成 | 種別・使用月 | S05 記録（その使用月） |
| S05 記録の「編集」 | 編集 | 検針票の ID | S05 記録（その使用月） |
| S03 ホームの「作成」「次を作成」 | 作成 | 種別・使用月 | S03 ホーム |

- 作成で開いたとき、同じ種別・同じ使用月の検針票がすでにあれば、その検針票の編集として開くこと。

## 表示項目

PC（幅 1024px 以上）では、左に基本の項目、右に内訳の表を並べ、「キャンセル」「保存」を右下に置く。

### 基本の項目

| 項目 | 必須 | 作成時 | 編集時 |
|---|---|---|---|
| 種別 | ○ | 表示だけ（変更できない） | 表示だけ（変更できない） |
| 使用月 | ○ | 表示だけ（「2026年8月分」の形。水道は「2026年7-8月分」） | 年と月を選ぶ。選べる範囲は 2000 年 1 月〜翌月 |
| 請求月 | | 年と月を選ぶ。未選択にもできる | 同左 |
| 契約 | ○ | 同じ種別の契約から選ぶ | 同左 |
| 請求額（税込） | ○ | 数字を入力。後ろに「円」 | 同左 |
| 使用期間 | | 開始日と終了日をカレンダーから選ぶ。間に「〜」 | 同左 |
| 使用量 | | 数字を入力。後ろに種別の単位（kWh または ㎥） | 同左 |
| メモ | | 複数行の文字を入力 | 同左 |

- 請求月で選べる年は、2000 年から翌年までとすること。
- 契約の選択肢は、同じ種別の契約をすべて（終了済みも含めて）開始日が新しい順に、契約の表示名（F02 の [`00_契約共通.md`](../02_契約/00_契約共通.md#契約の表示名)）で並べること。
- 同じ種別の契約が 1 件も無いときは、契約の欄に「電気の契約が登録されていません。設定から契約を登録してください。」（「電気」は種別名）と表示し、「保存」を押せなくすること。

### 内訳

| 項目 | 内容 |
|---|---|
| 見出し | 「内訳」 |
| 各行 | 項目名・金額の入力欄（後ろに「円」）。その下に小さく「数量」「単価」の入力欄（見本「任意」） |
| 内訳の合計 | 「内訳の合計」と、入力した金額の合計（「3,950 円」の形） |
| 行が無いとき | 「この契約には内訳項目が選ばれていません。」 |

- 行は次の順に並べること。
  - 作成時：選んでいる契約の内訳項目（外したものを除く）を表示順に並べる。
  - 編集時：保存済みの内訳を保存した順に並べ、その後に、選んでいる契約の内訳項目のうちまだ並んでいないものを表示順に並べる。
- 契約を選び直したときは、選び直した契約の内訳項目を表示順に並べ直すこと（入力した内訳の金額・数量・単価は消える）。
- 内訳の合計は、金額を入力した行だけを足し、入力のたびに計算し直すこと。

### ボタン

| ボタン | 位置 |
|---|---|
| 「キャンセル」 | 「保存」の左 |
| 「保存」 | 画面の最下部（PC では右下） |

## 初期値

作成時だけ、次の値を入れておくこと。編集時は保存済みの値を入れる。

| 項目 | 初期値 | 決められないとき |
|---|---|---|
| 契約 | 使用月の時点で契約中の、同じ種別の契約 | 未選択 |
| 請求月 | 同じ契約の直前の検針票と同じ「使用月から請求月までの月数」を、使用月に足した月 | 未選択（直前の検針票が無い、または直前の検針票の請求月が空のとき） |
| 使用期間の開始日 | 同じ契約の直前の検針票の、使用期間の終了日の翌日 | 空（直前の検針票が無い、または直前の検針票の使用期間が空のとき） |
| 使用期間の終了日 | 開始日の 1 か月後の前日（水道は 2 か月後の前日）。1 か月後（水道は 2 か月後）に同じ日が無いとき（1 月 31 日の 1 か月後など）は、その月の末日とする | 空（開始日が空のとき） |
| 内訳 | 契約で選んだ内訳項目を表示順に並べる（金額・数量・単価は空） | — |

- 「使用月の時点で契約中」「直前の検針票」の決め方は [`00_検針票の記録共通.md`](00_検針票の記録共通.md) に従う。
- 初期値は画面を開いたときに 1 回だけ入れること。契約を選び直したときは、内訳だけを並べ直す。

## 入力チェック

「保存」を押したときに確かめ、エラーは該当する入力欄の下に表示する。数値の受け付け方は [`00_検針票の記録共通.md`](00_検針票の記録共通.md#数値の入力) に従う。

| 項目 | チェック | 表示する文言 |
|---|---|---|
| 使用月（編集時） | 2000 年 1 月〜翌月の範囲の外 | 使用月は2000年1月から翌月までの範囲で選択してください。 |
| 使用月（編集時） | 同じ種別・同じ使用月の別の検針票がある | 2026年8月分のガスの検針票はすでに登録されています。 |
| 契約 | 未選択 | 契約を選択してください。 |
| 請求額 | 空 | 請求額を入力してください。 |
| 請求額 | 整数でない、または 0〜999,999 の外 | 請求額は0〜999,999の整数で入力してください。 |
| 使用期間 | 開始日と終了日の片方だけ入力 | 使用期間は開始日と終了日の両方を入力してください。 |
| 使用期間 | 日付として正しくない | 正しい日付を入力してください。 |
| 使用期間 | 終了日が開始日より前 | 終了日は開始日以降の日付を入力してください。 |
| 使用量 | 数値でない、範囲の外、または小数 2 桁以上 | 使用量は0〜99,999.9の数値（小数1桁まで）で入力してください。 |
| 内訳の金額 | 整数でない、または −999,999〜999,999 の外 | 金額は−999,999〜999,999の整数で入力してください。 |
| 内訳の数量 | 数値でない、範囲の外、または小数 2 桁以上 | 数量は0〜99,999.9の数値（小数1桁まで）で入力してください。 |
| 内訳の単価 | 数値でない、範囲の外、または小数 4 桁以上 | 単価は−9,999.999〜9,999.999の数値（小数3桁まで）で入力してください。 |
| 内訳 | 数量か単価を入力したのに金額が空 | 数量・単価を入力した項目は、金額も入力してください。 |
| メモ | 前後の空白を除いて 201 文字以上 | メモは200文字以内で入力してください。 |

- 「すでに登録されています」の文言の年月・種別は、選んだ使用月と種別に合わせること。
- メモは前後の空白を除いて保存すること。

## 警告

- 内訳の金額が 1 つ以上入力されていて、内訳の合計が請求額と一致しないときは、内訳の合計の下に次の文言を表示すること。保存は止めない。
  - 「内訳の合計（3,950 円）が請求額（3,850 円）と一致しません。このまま保存もできます。」
- 金額や請求額を変えるたびに判定し直すこと。

## 操作と遷移先

| 操作 | 動き | 遷移先 |
|---|---|---|
| 契約を選び直す（内訳に入力済みの値が無い） | 内訳を並べ直す | — |
| 契約を選び直す（内訳に入力済みの値がある） | 確認を出す（下記） | — |
| 確認で「変更する」を押す | 契約を変え、内訳を並べ直す | — |
| 確認で「キャンセル」を押す | 契約を元に戻して確認を閉じる | — |
| 「保存」を押す（チェックを通過） | 検針票を保存する | S05 記録（保存した検針票の使用月） |
| 「キャンセル」を押す | 保存せずに戻る（確認は出さない） | 元の画面 |
| 入力内容を変えた後にタブを押す | [`../00_全体共通.md`](../00_全体共通.md#タブ) の確認を出す | 「移動する」を押したらそのタブの画面 |

- 契約の確認では、「契約を変更すると、入力した内訳が消えます。変更しますか？」と表示し、「変更する」「キャンセル」ボタンを置くこと。
- 「保存」を押してから処理が終わるまでは、「保存」を押せなくすること。

## エラー時の表示文言

| 場面 | 表示する文言 |
|---|---|
| 作成の保存の直前に、同じ種別・同じ使用月の検針票が登録されたとき | 2026年8月分のガスの検針票はすでに登録されています。 |
| 選んだ契約が世帯に無い、または種別が違うとき | 契約が見つかりません。選び直してください。 |
| 使用月がこの画面を開いた後に扱える範囲の外になったとき | 使用月は2000年1月から翌月までの範囲で選択してください。 |

このほか、入力チェックの表と [`../00_全体共通.md`](../00_全体共通.md#共通のエラー表示) の共通の文言を使う。

## DB への影響

| 操作 | テーブル | 内容 |
|---|---|---|
| 作成で保存 | MeterReading | 1 行作る（`utilityType` は選んだ契約の種別） |
| 作成で保存 | MeterReadingItem | 金額を入力した行だけを、画面の並び順で作る（`sortOrder` = 1 から。`name`・`category` は契約の内訳項目の値を控える） |
| 編集で保存 | MeterReading | 入力した値で更新する |
| 編集で保存 | MeterReadingItem | この検針票の行を消し、金額を入力した行を作成時と同じ方法で作り直す。保存済みの内訳の `name`・`category` は、保存済みの控えをそのまま使う |

- 検針票と内訳の更新は、1 つのトランザクションで行うこと。
- 契約（Contract・ContractItem）は変更しないこと。
