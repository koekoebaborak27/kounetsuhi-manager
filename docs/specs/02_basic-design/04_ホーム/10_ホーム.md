# S03 ホーム

## 目的

アプリを開いてすぐに、今月の光熱費が前回・前年同月と比べて高いのかを確かめる。

## 表示項目

上から「今年の合計」、電気・ガス・水道のカードの順に並べる。PC（幅 1024px 以上）では 3 枚のカードを横に並べる。

### 今年の合計

| 項目 | 内容 |
|---|---|
| 見出し | 「今年の合計（1〜9月分）」の形 |
| 金額 | 「186,470 円」の形 |

- 背景色をカードと変えて目立たせること。計算方法は [`00_ホーム共通.md`](00_ホーム共通.md#今年の合計) に従う。

### 種別ごとのカード（検針票が 1 件以上ある種別）

| 項目 | 内容 |
|---|---|
| 種別名と使用月 | 「電気 8月分」の形。水道は「水道 7-8月分」。使用月が今年でないときは「電気 2025年12月分」のように年を付ける |
| ボタン | 「次月分を作成」 |
| 請求額 | 最新の検針票の請求額（「12,640 円」の形） |
| 前回比 | 「前回比 +15.1%」の形 |
| 前年同月比 | 「前年同月比 −5.5%」の形 |
| 1 日あたりの金額 | 「421 円/日」の形 |

- 各値の決め方と、表示できないときの「—」は [`00_ホーム共通.md`](00_ホーム共通.md) に従う。
- 1 日あたりの金額が出せないときは、「1日あたり —」と表示すること（前回比・前年同月比は「前回比 —」の形）。

### 種別ごとのカード（検針票が 1 件も無い種別）

| 項目 | 内容 |
|---|---|
| 種別名 | 「ガス」など |
| 表示 | 「未登録」 |
| ボタン | 「作成」 |

## 入力チェック

なし。

## 操作と遷移先

| 操作 | 遷移先 |
|---|---|
| 「次月分を作成」を押す | S04 検針票の入力（作成。種別はそのカード、使用月は [次月分を作成する使用月](00_ホーム共通.md#次月分を作成する使用月)） |
| 「作成」を押す | S04 検針票の入力（作成。種別はそのカード、使用月は前月） |

- 「次月分を作成」の使用月が翌月より先になるときは、ボタンを押せなくすること。

## エラー時の表示文言

[`../00_全体共通.md`](../00_全体共通.md#共通のエラー表示) の共通の文言を使う。
