# S06 グラフ（年比較タブ）

## 目的

前年より高いか、季節によってどう変わるかを確かめる。

## 表示項目

| 項目 | 内容 |
|---|---|
| 種別の切り替え | 「電気」「ガス」「水道」「合計」。最初は「電気」 |
| 値の切り替え | 「金額」「使用量」。最初は「金額」 |
| グラフ | 年ごとに 1 本の折れ線。内容は下の表 |
| 凡例 | 「2026年」「2025年」「2024年」の形。グラフの下（PC ではグラフの右に縦に並べる） |

### グラフ

| 種別の切り替え | 横軸 | 1 点の値 |
|---|---|---|
| 電気・ガス | 「1」〜「12」（月）。下に「（月）」 | その年・その使用月の検針票の請求額（または使用量） |
| 水道 | 2 か月単位の区切り 6 つ（「1-2月」…「11-12月」など） | その年・その区切りの水道の検針票の請求額（または使用量） |
| 合計 | 「1」〜「12」（月） | その年・その使用月の 3 種別の請求額の合計。検針票が 1 件も無い月は点を置かない |

- 描く年は今年・前年・前々年の 3 年とすること。今年は太線、前年・前々年は細線とする。
- 3 年のうち検針票が 1 件も無い年は、折れ線も凡例も出さないこと。この判定は、表示中の種別ごとに行う（「合計」は 3 種別のどれか 1 件でもあれば「ある」）。例：ガスを選んだとき、その年に電気の検針票だけがあっても、その年は出さない。種別を切り替えると凡例の年も変わる。
- 前年の折れ線は実線の細線、前々年は点線の細線にすること（色だけに頼らず見分けるため）。
- 金額の縦の目盛りは 0 から始め、5 千・1 万・2 万・5 万…円のキリのよい刻みで 5 本以内に収めること（「0.45万」のような中途半端な目盛りにしない）。使用量の目盛りは自動に任せる。
- 縦の目盛りは、金額のときは「2万」「1万」「0」のように万円単位で、使用量のときは「（kWh）」または「（㎥）」を添えて表示すること。
- 水道の区切り方は [`00_グラフ共通.md`](00_グラフ共通.md#水道の-2-か月単位の区切り) に従う。区切りが年をまたぐとき（「12-1月」）は、後ろの月の年の点とする。

## 入力チェック

なし。

## 操作と遷移先

| 操作 | 動き |
|---|---|
| 種別を押す | グラフを切り替える。「合計」を選んだときは「使用量」を押せなくし、「使用量」を選んでいたら「金額」に切り替える |
| 「金額」「使用量」を押す | 縦軸の値を切り替える |

- どの操作でも別の画面へは移らない。
