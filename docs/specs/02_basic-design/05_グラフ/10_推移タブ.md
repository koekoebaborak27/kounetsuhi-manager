# S06 グラフ（推移タブ）

## 目的

最近の光熱費が増えているかを確かめる。

## 表示項目

| 項目 | 内容 |
|---|---|
| 期間の切り替え | 「12か月」「24か月」。最初は「12か月」 |
| 種別の切り替え | 「すべて」「電気」「ガス」「水道」。最初は「すべて」 |
| グラフ | 下の表 |
| 注記 | 「すべて」のときだけ、グラフの下に「水道は 2 か月分をまとめて後ろの月に載せています」 |
| 選んだ月のカード | グラフの下（PC ではグラフの右）。内容は下の表 |

### グラフ

| 種別の切り替え | 横軸 | 棒 | 折れ線 |
|---|---|---|---|
| すべて | 前月までの 12（24）か月。文字は月の数字（「9」「10」…） | 使用月ごとに電気・ガス・水道の請求額を色分けして積み上げる。左の目盛りは「（円）」 | なし |
| 電気・ガス | 前月までの 12（24）か月 | 請求額。左の目盛りは「（円）」 | 使用量。右の目盛りは「（kWh）」または「（㎥）」 |
| 水道 | 前月までの 12（24）か月に入る 2 か月単位の区切り（6 または 12 個） | 同上 | 同上（「（㎥）」） |

- 「前月」は今日が属する月の前の月とすること。水道の区切りは、後ろの月が前月以前のものを新しいほうから 6（12）個とる。区切り方は [`00_グラフ共通.md`](00_グラフ共通.md#水道の-2-か月単位の区切り) に従う。
- 「すべて」と「24か月」では、横軸の文字が重なるときは 1 つおきに表示すること。
- 凡例（「電気」「ガス」「水道」、または「請求額」「使用量」）をグラフの下に置くこと。

### 選んだ月のカード

| 項目 | 内容 |
|---|---|
| 見出し | 「2026年8月分 24,500 円」の形（選んだ月の 3 種別の合計） |
| 種別ごとの行 | 電気・ガス・水道の順に種別名と請求額。水道は「水道（7-8月分）」の形。その月の検針票が無い種別は「未登録」 |

- 最初は、横軸の一番右の月（区切り）を選んだ状態とすること。
- 水道の区切りを選んだときは、その区切りの後ろの月を「選んだ月」とする。
- 選んだ月に検針票が 1 件も無いときは、合計を「0 円」、各種別を「未登録」と表示すること。

## 入力チェック

なし。

## 操作と遷移先

| 操作 | 動き |
|---|---|
| 「12か月」「24か月」を押す | 横軸の期間を切り替える。選んだ月は一番右の月に戻す |
| 種別を押す | グラフを切り替える。選んだ月は一番右の月（区切り）に戻す |
| 棒（または横軸のその月の位置）をタップする | その月を選び、カードの内容を切り替える。選んだ月の棒を強調する |

- どの操作でも別の画面へは移らない。
