# S06 グラフ（年間タブ）

## 目的

1 年でいくらかかっているかを確かめる。

## 表示項目

| 項目 | 内容 |
|---|---|
| 今年の合計 | 見出し「今年の合計」、金額（「186,470 円」の形）、その下に「前年比 −4.8%」の形 |
| 月平均 | 見出し「月平均」、金額（「23,309 円」の形） |
| 年ごとの合計 | 見出し「年ごとの合計（円）」と表。列は「年」「電気」「ガス」「水道」「合計」 |

### 計算方法

| 値 | 計算方法 | 表示できないとき |
|---|---|---|
| 今年の合計 | 使用月が今年の検針票の請求額を 3 種別すべて足した金額 | 今年の検針票が無いときは「0 円」 |
| 前年比 | （今年の合計 − 前年の同じ期間の合計）÷ 前年の同じ期間の合計 × 100。前年の同じ期間は、前年の 1 月から「今年の記録がある最後の月」と同じ月まで | 今年の検針票が無い、前年の同じ期間の検針票が無い、または前年の同じ期間の合計が 0 円のときは「前年比 —」 |
| 月平均 | 今年の合計 ÷ 今年の記録のある月数。円未満は四捨五入 | 今年の検針票が無いときは「—」 |

- 「今年の記録がある最後の月」は、今年の検針票（種別を問わない）のうち最も新しい使用月とすること。
- 「記録のある月数」は、今年の使用月のうち、どれか 1 種別でも検針票がある月の数とすること。
- 前年比の表示（小数 1 桁、「+」「−」、増は赤・減は青）は F04 の [`00_ホーム共通.md`](../04_ホーム/00_ホーム共通.md#増減率の計算と表示) と同じとすること。

### 年ごとの合計の表

- 検針票が 1 件でもある年を、新しい年から順にすべて並べること。
- 各列には、その年の使用月の検針票の請求額を種別ごとに足した金額を、3 桁ごとのカンマつきで表示すること（「円」は見出しに付けるので各欄には付けない）。その年にその種別の検針票が無いときは「—」とする。
- 「合計」は 3 種別の合計とすること。
- 今年の行は、年の横に「（1〜8月）」の形で集計した期間（1 月〜今年の記録がある最後の月）を添えること。最後の月が 1 月のときは「（1月）」とする。
