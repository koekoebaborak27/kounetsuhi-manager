## Contract（契約）

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | cuid |
| householdId | 世帯ID | text | ○ | | Household.id への参照 |
| utilityType | 種別 | enum `UtilityType`（`ELECTRICITY` / `GAS` / `WATER`） | ○ | | 種別 |
| companyName | 会社名 | text | ○ | | 会社名。1〜30 文字 |
| planName | プラン名 | text | | | プラン名。30 文字以内 |
| startDate | 開始日 | date | ○ | | 開始日 |
| endDate | 終了日 | date | | | 終了日。空は契約中。開始日以降 |
| memo | メモ | text | | | メモ。200 文字以内 |
| createdAt | 作成日時 | timestamptz | ○ | | 作成日時 |
| updatedAt | 更新日時 | timestamptz | ○ | | 更新日時 |

- `householdId` と `utilityType` の組み合わせに索引を付けること。
- 行を消す操作は設けないこと。

## ContractItem（契約の内訳項目）

契約ごとに選んだ内訳項目。検針票の入力画面に並べる項目と順番を決める。

| 列 | 論理名 | 型 | 必須 | 一意 | 説明 |
|---|---|---|---|---|---|
| id | ID | text | ○ | ○ | cuid |
| contractId | 契約ID | text | ○ | ○（name と組み合わせて） | Contract.id への参照 |
| name | 項目名 | text | ○ | ○（contractId と組み合わせて） | 項目名。候補の項目名、または「その他」で入力した名前（1〜30 文字） |
| category | 分類 | enum `ItemCategory`（`BASIC` / `USAGE` / `ADJUSTMENT` / `LEVY` / `DISCOUNT` / `OTHER`） | ○ | | 集計用の分類 |
| isCustom | その他の項目か | boolean | ○ | | 「その他」で追加した項目なら true |
| sortOrder | 表示順 | integer | ○ | | 表示順。小さいほど上 |
| removedAt | 外した日時 | timestamptz | | | 外した日時。空なら選択中 |
| createdAt | 作成日時 | timestamptz | ○ | | 作成日時 |
| updatedAt | 更新日時 | timestamptz | ○ | | 更新日時 |

- 項目を外したときは行を消さず、`removedAt` に日時を入れること（検針票の内訳から参照されているため）。
- 外した項目と同じ名前の項目を再び選んだときは、新しい行を作らず、その行の `removedAt` を空に戻し、`category`・`isCustom`・`sortOrder` を選び直した内容で更新すること。
- 選択中の項目の `sortOrder` は、保存のたびに画面の並び順どおり 1 から振り直すこと。
