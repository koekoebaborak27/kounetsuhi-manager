# S08 契約

## 目的

契約を登録・編集し、検針票の入力に使う内訳項目を選ぶ。画面名は登録・編集とも「契約」とする。

## 表示項目

PC（幅 1024px 以上）では、左に契約の項目、右に内訳項目を並べ、「保存」を右下に置く。

### 契約の項目

| 項目 | 必須 | 入力のしかた | 登録時の初期値 |
|---|---|---|---|
| 種別 | ○ | 「電気」「ガス」「水道」の 3 つのボタンから 1 つ選ぶ | 未選択 |
| 会社名 | ○ | 文字を入力 | 空 |
| プラン名 | | 文字を入力 | 空 |
| 開始日 | ○ | カレンダーから選ぶ | 空 |
| 終了日 | | カレンダーから選ぶ。空欄の見本として「空欄＝契約中」を薄く表示する | 空 |
| メモ | | 複数行の文字を入力 | 空 |

- 編集時は、保存済みの値を入れて表示すること。
- 検針票が 1 件でもある契約の編集では、種別のボタンを押せなくし、その下に「検針票が登録済みのため、種別は変更できません。」と表示すること。

### 内訳項目

| 項目 | 内容 |
|---|---|
| 見出し | 「内訳項目」 |
| ひな形 | 選択している種別のひな形を選ぶ欄（未選択時の表示は「ひな形を選ぶ」）と「まとめて選ぶ」ボタン |
| 選んだ項目の一覧 | 各行に「≡」（並べ替えのつまみ）・項目名・［分類］・「×」 |
| 選んだ項目が無いとき | 「内訳項目が選ばれていません。」 |
| 候補から追加 | 見出し「候補から追加」と、選択している種別の候補のうちまだ選んでいない項目を「＋ 項目名」のボタンで並べる |
| その他 | 項目名の入力欄（見本「その他（項目名を入力）」）・分類を選ぶ欄（見本「分類」）・「追加」ボタン |

- 種別が未選択のときは、内訳項目の区画に「種別を選ぶと内訳項目を選べます。」とだけ表示すること。
- 候補の並び順・分類、ひな形の内容は [`00_契約共通.md`](00_契約共通.md#内訳項目の候補) に従う。

### ボタン

| ボタン | 位置 |
|---|---|
| 「保存」 | 画面の最下部（PC では右下） |

## 入力チェック

「保存」を押したときに確かめ、エラーは該当する入力欄の下に表示する。文字数は前後の空白を除いて数え、前後の空白を除いて保存すること。

| 項目 | チェック | 表示する文言 |
|---|---|---|
| 種別 | 未選択 | 種別を選択してください。 |
| 会社名 | 空 | 会社名を入力してください。 |
| 会社名 | 31 文字以上 | 会社名は30文字以内で入力してください。 |
| プラン名 | 31 文字以上 | プラン名は30文字以内で入力してください。 |
| 開始日 | 空 | 開始日を入力してください。 |
| 開始日・終了日 | 日付として正しくない | 正しい日付を入力してください。 |
| 終了日 | 開始日より前 | 終了日は開始日以降の日付を入力してください。 |
| メモ | 201 文字以上 | メモは200文字以内で入力してください。 |

「その他」の「追加」を押したときは次を確かめ、エラーは「その他」の欄の下に表示する。

| 項目 | チェック | 表示する文言 |
|---|---|---|
| 項目名 | 空 | 項目名を入力してください。 |
| 項目名 | 31 文字以上 | 項目名は30文字以内で入力してください。 |
| 項目名 | 選んだ項目の一覧に同じ名前がある | 同じ名前の項目がすでにあります。 |
| 分類 | 未選択 | 分類を選択してください。 |

## 警告

- 開始日が入力されていて、同じ種別の別の契約と期間が重なるときは、終了日の下に次の文言を表示すること。保存は止めない。重なる契約が複数あるときは、表示名を「、」でつなぐ。
  - 「同じ種別で契約期間が重なる契約があります（あおば電気 標準プラン）。このまま保存もできます。」
- 判定は種別・開始日・終了日を変えるたびに行うこと。判定方法は [`00_契約共通.md`](00_契約共通.md#契約期間の重なり) に従う。

## 操作と遷移先

| 操作 | 動き | 遷移先 |
|---|---|---|
| 種別のボタンを押す（内訳項目が 0 件） | 種別を切り替える | — |
| 種別のボタンを押す（内訳項目が 1 件以上） | 確認を出す（下記） | — |
| 確認で「変更する」を押す | 種別を切り替え、選んだ内訳項目をすべて外す | — |
| 確認で「キャンセル」を押す | 種別を変えずに確認を閉じる | — |
| ひな形を選んで「まとめて選ぶ」を押す | ひな形の項目のうちまだ選んでいないものを、ひな形の順で一覧の最後に加える。すでに選んでいる項目はそのまま残す | — |
| 「＋ 項目名」を押す | その候補を一覧の最後に加える | — |
| 「その他」の「追加」を押す（チェックを通過） | 入力した名前と分類の項目を一覧の最後に加え、入力欄を空に戻す | — |
| 「≡」をつかんで上下に動かす | 表示順を並べ替える | — |
| 「×」を押す | その項目を一覧から外す。候補の項目なら「候補から追加」に戻る | — |
| 「保存」を押す（チェックを通過） | 契約と内訳項目を保存する | S07 設定 |
| 「契約を削除」を押し、確認で「削除する」を押す | 検針票が無い契約と、その内訳項目を消す | S07 設定 |

- 種別の確認では、「種別を変更すると、選んだ内訳項目がすべて外れます。変更しますか？」と表示し、「変更する」「キャンセル」ボタンを置くこと。
- 一覧の追加・並べ替え・外すは画面の中だけで行い、「保存」を押したときにまとめて DB へ反映すること。
- 「まとめて選ぶ」は、ひな形が未選択のときは押せなくすること。
- 「保存」を押してから処理が終わるまでは、「保存」を押せなくすること。
- 保存せずに戻るときは、タブの「設定」を押す（確認は出さない）。
- 編集時だけ「契約を削除」ボタンを置き、確認で「契約を削除しますか？」と表示する。検針票が 1 件でもある契約は、削除ボタンを押せないようにする。

## エラー時の表示文言

| 場面 | 表示する文言 |
|---|---|
| 保存の直前に検針票が登録され、種別を変更できなくなったとき | 検針票が登録済みのため、種別は変更できません。 |
| 削除の直前に検針票が登録され、削除できなくなったとき | 検針票が登録済みのため、契約は削除できません。 |

このほか、入力チェックの表と [`../00_全体共通.md`](../00_全体共通.md#共通のエラー表示) の共通の文言を使う。

## DB への影響

| 操作 | テーブル | 内容 |
|---|---|---|
| 登録で保存 | Contract | 1 行作る |
| 登録で保存 | ContractItem | 選んだ項目を画面の並び順で作る（`sortOrder` = 1 から） |
| 編集で保存 | Contract | 入力した値で更新する |
| 編集で保存 | ContractItem | 一覧に残っている項目は `sortOrder` を振り直す。新しく加えた項目は行を作る（同じ名前の外した行があればそれを戻す）。外した項目は `removedAt` に日時を入れる |
| 削除 | Contract / ContractItem | 検針票が無い契約だけ、内訳項目とともに消す |

- 契約と内訳項目の更新は、1 つのトランザクションで行うこと。
- 登録済みの検針票（MeterReading・MeterReadingItem）は変更しないこと。
