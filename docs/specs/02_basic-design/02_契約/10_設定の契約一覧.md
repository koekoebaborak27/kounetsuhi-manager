# S07 設定 — 契約の一覧

S07 設定のうち、「契約」の区画。画面のほかの区画は F01 の [`30_設定.md`](../01_認証と世帯/30_設定.md)。

## 目的

世帯の契約を「契約中」と「終了済み」に分けて一覧し、登録・編集の画面を開く。

## 表示項目

| 項目 | 内容 |
|---|---|
| 見出し | 「契約」と、その横に「契約を登録」ボタン |
| 小見出し | 「契約中」「終了済み」。該当する契約が無い小見出しは出さない |
| 各行 | 種別の色の点・契約の表示名・期間（「YYYY/MM/DD〜」または「YYYY/MM/DD〜YYYY/MM/DD」）・「変更」ボタン |
| 契約が 1 件も無いとき | 「登録された契約はありません。」 |

- 契約中と終了済みの分け方は [`00_契約共通.md`](00_契約共通.md#契約中と終了済み) に従う。
- 各小見出しの中は「電気・ガス・水道」の順に並べ、同じ種別の中では開始日が新しい順に並べること。
- 終了済みの行は、文字を薄く表示すること。

## 入力チェック

なし。

## 操作と遷移先

| 操作 | 遷移先 |
|---|---|
| 「契約を登録」を押す | S08 契約（登録） |
| 「変更」を押す | S08 契約（その契約の編集） |

## エラー時の表示文言

[`../00_全体共通.md`](../00_全体共通.md#共通のエラー表示) の共通の文言を使う。

## DB への影響

なし（Contract を読むだけ）。
