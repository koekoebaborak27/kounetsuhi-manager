## 書くときの注意

- **実際の値（プロジェクト番号・本番URL・接続文字列・シークレット）を書かない。** `<プロジェクトID>` のようなプレースホルダにする。
- 画面のクリック手順は、その画面の名称と押すボタン名まで書く（後から自分で再現できるように）。
- 手順の途中で決めた設定値は、`docs/todo/notes/` ではなくここに残す（構築手順の一部のため）。
- 無料プランの制限の数値は変わりうるため、作業するときに公式ページで再確認する。
