# F02 契約

電気・ガス・水道の契約（会社・プラン）を登録し、会社やプランの切り替えを記録するための要件。

## 契約の登録

- 契約は次の項目を持つこと。

  | 項目 | 必須 | 備考 |
  |---|---|---|
  | 種別 | ○ | 電気・ガス・水道 |
  | 会社名 | ○ | |
  | プラン名 | | |
  | 開始日 | ○ | |
  | 終了日 | | 空のときは契約中とする |
  | メモ | | |

- 会社やプランを切り替えたときは、古い契約に終了日を入れ、新しい契約を登録すること。
- 同じ種別で契約期間が重なるときは警告を表示すること（保存は止めない）。
- 契約は削除できないこと。使わなくなった契約は終了日を入れて終了扱いにする。
- 使用量の単位は、電気は kWh、ガス・水道は ㎥ とすること。

## 内訳項目の選択

契約ごとに、請求額の内訳として使う項目を選んでおくこと。毎月の入力では、選んだ項目が並び、金額だけを入れればよいようにする。

- 項目はアプリで用意した候補から選べること。候補に無い項目だけ「その他」として名前を自由に入力できること。「その他」の項目は、集計用の分類を利用者が選ぶこと。

  | 種別 | 候補 |
  |---|---|
  | 電気 | 基本料金、電力量料金 第 1 段階、電力量料金 第 2 段階、電力量料金 第 3 段階、昼間料金、夜間料金、燃料費調整額、再エネ賦課金、補助値引き |
  | ガス | 基本料金、従量料金、原料費調整額、補助値引き |
  | 水道 | 上水道、下水道 |

- 各項目は、集計用の分類（基本料金・従量料金・調整額・賦課金・割引と補助・その他）を持つこと。
- よく使う項目の組み合わせをひな形として用意し、1 回の操作でまとめて選べること（例：「従量電灯 B（3 段階）」）。
- 項目の表示順を並べ替えられること。
- 選んだ項目を外せること。
- 候補とひな形はアプリのコードの中に持ち、画面から追加・変更する機能は作らないこと。
