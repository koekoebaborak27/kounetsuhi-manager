# F03 検針票の記録

検針票を月ごとに記録・確認・修正するための要件。

## 記録画面

- 使用月を 1 か月ずつ切り替えて表示すること（「◀ 2026 年 6 月分 ▶」の形）。最初は前月を表示する（当月分はまだ検針票が届いていないことが多いため）。
- 表示中の使用月について、電気・ガス・水道を 1 行ずつ並べること。
  - 検針票が登録済みの種別：請求額と「編集」ボタンを表示する。水道は「5-6 月分」のようにまとめた期間も表示する。
  - 未登録の種別：「未登録」の文字と「作成」ボタンを表示する。
  - 水道で、前月に検針票が登録済みかつ当月が未登録のとき：「隔月のため記録なし」と薄く表示する。この場合も「作成」はできる。
- 過去の月へさかのぼって、同じ操作で登録できること（初回に過去 1 年分をまとめて入力するため）。

## 検針票の入力

新規作成と編集は同じ画面とすること。

| 項目 | 必須 | 入力のルール |
|---|---|---|
| 種別 | ○ | 作成時は記録画面で選んだ種別に固定する |
| 使用月 | ○ | 検針票の「○月分」。作成時は記録画面で表示中の月に固定する |
| 請求月 | | 検針票の請求の年月。記録のためだけに持ち、集計・比較には使わない。年月を選んで入力する |
| 契約 | ○ | 同じ種別の契約から選ぶ |
| 請求額 | ○ | 税込の請求額。0 以上の整数（円） |
| 使用期間の開始日・終了日 | | カレンダーから選んで入力する。終了日は開始日以降であること |
| 使用量 | | 0 以上、小数 1 桁まで |
| 内訳 | | 契約で選んだ内訳項目が並ぶ。各項目に金額を入れる（割引・補助は負の金額）。数量・単価は任意 |
| メモ | | |

- 同じ契約・同じ使用月の検針票は 1 件だけとすること。
- 内訳の合計が請求額と一致しないときは警告を表示すること（端数や項目漏れがあるため、保存は止めない）。
- 保存したら、その使用月の記録画面に戻ること。
- 保存の横に、保存せずに元の画面へ戻る「キャンセル」ボタンを置くこと。
- 入力中に下部タブ（PC では左側のメニュー）で別の画面へ移ろうとしたときは、入力内容が失われることを知らせて確認すること。
- 検針票は削除できないこと。

## 入力の手間を減らす初期値

新規作成のとき、次の値をあらかじめ入れておくこと。

| 項目 | 初期値 |
|---|---|
| 契約 | 使用月の時点で契約中の、同じ種別の契約 |
| 請求月 | 同じ契約の直前の検針票と同じ「使用月から請求月までの間隔」を空けた月 |
| 使用期間の開始日 | 同じ契約の直前の検針票の、使用期間の終了日の翌日 |
| 使用期間の終了日 | 開始日の 1 か月後の前日（水道は 2 か月後の前日） |
| 内訳 | 契約で選んだ内訳項目を表示順に並べる（金額は空） |
